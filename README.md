# Brute-Force Attack Detection & Auto-Ban System

**Level 5 Cybersecurity Project - Complete Stack Live Project**

## Overview
A real-time brute-force attack detection and auto-ban system with live dashboard and external device integration.

## Architecture
- Frontend: React + Vite + Tailwind (Vercel)
- Backend: FastAPI Python (Render)
- Database: PostgreSQL (Neon)
- Cache: Redis (Upstash)
- Alerts: Telegram Bot
- External Devices: Mobile phone + Python agent (2nd laptop/VM)

## Features
- Real-time brute-force detection
- Auto IP banning (5 attempts in 60s => 10 min ban)
- Live attack dashboard
- Telegram instant alerts
- External device integration (phone + agent)
- API documentation (auto Swagger)
